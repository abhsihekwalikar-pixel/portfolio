> **From college projects to production-grade engineering.** 
> HIGH5 is a premium, multi-page portfolio website built by a team of five dedicated engineering students. We specialize in crafting blazing-fast, personalized web experiences, educational platforms, and business sites that refuse to blend in.

  

---

##  Features

*   **Premium UI/UX:** Deep black aesthetic with emerald green accents, designed for a high-end agency feel.
*   **Advanced Animations:** Powered by Framer Motion, featuring custom trailing cursors, mouse-following spotlights, and masked scroll text reveals.
*   **Multi-Page Routing:** Seamless, smooth page transitions using React Router DOM without full page reloads.
*   **Fully Responsive:** Flawless experience across desktop, tablet, and mobile devices.
*   **Functional Contact Form:** Integrated with EmailJS to send project inquiries directly to our inbox.
*   **Performance First:** Built with Vite for lightning-fast build times and optimized production bundles.

---

##  Tech Stack

*   **Frontend Framework:** [React.js](https://react.dev/) (Vite)
*   **Routing:** [React Router DOM](https://reactrouter.com/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Animations:** [Framer Motion](https://www.framer.com/motion/)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Form Handling:** [EmailJS](https://www.emailjs.com/)
*   **Hosting:** [Vercel](https://vercel.com/)
